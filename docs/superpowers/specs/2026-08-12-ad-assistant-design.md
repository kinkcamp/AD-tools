# AD 域控助手 — 设计文档

## 项目概述

企业 AD 域控助手是一款桌面端应用，用于高效管理 Active Directory 域控用户。支持批量创建/修改/删除用户、批量修改密码、批量加入组、批量修改属性、快速搜索与双击改密等功能，全程 SSL 安全连接。

## 技术栈

| 层级 | 技术选型 |
|------|---------|
| 桌面框架 | Tauri 2.x |
| 前端 | React 18 + TypeScript |
| UI 组件库 | Ant Design 5.x（暗色主题定制） |
| 后端 | Rust（Tauri 内置） |
| LDAP | `ldap3` Rust crate |
| 文件解析 | `calamine`（Excel）、`csv`（CSV） |
| 构建 | Vite |

## 页面清单（7 个页面）

### 1. 用户搜索与管理（主界面）

- 全局搜索栏：搜索用户名、姓名、邮箱、部门
- OU 筛选下拉
- 统计卡片行：搜索结果数 / 活跃 / 已禁用 / 已锁定
- 用户表格：复选框、用户名、姓名、邮箱、部门、状态、最后登录
- 分页组件
- 右键菜单：修改密码 / 编辑属性 / 加入组 / 启用禁用 / 解锁 / 删除

### 2. 批量创建用户

- 步骤条：上传文件 → 预览确认 → 执行创建 → 完成
- 模板下载卡片：CSV 模板 / Excel 模板
- 文件上传区：拖拽 + 点击，支持 .csv / .xlsx / .xls
- 数据预览表格：带验证状态（通过/警告/错误）
- 确认创建按钮

### 3. 批量修改密码

- 密码策略配置：密码模式（文件指定/统一/随机）、密码长度
- 选项：强制下次登录修改、导出密码清单
- 文件上传区
- 执行进度条 + 成功/失败统计
- 实时操作日志面板

### 4. 批量加入组

- 目标组选择：搜索框 + 已选组标签
- 文件上传区
- 预览表格：用户名、姓名、当前所属组、操作状态（已在组/将加入）

### 5. 批量修改属性

- 属性字段下拉选择（部门/职位/电话/邮箱/经理/办公地点/描述/员工ID）
- 修改方式：统一设置 / 文件读取 / 追加值
- 多属性规则叠加：可添加多条属性修改规则
- 文件上传区
- 预览表格：新旧值对比（绿色高亮新值）

### 6. 双击修改密码（弹窗交互）

- 搜索用户后双击触发
- 模态弹窗：新密码 / 确认密码 / 密码强度指示
- 选项：强制下次登录修改、生成随机密码
- 确认/取消按钮

### 7. 连接设置

- AD 域控连接：地址、端口、Base DN、协议版本
- 身份验证：绑定 DN、密码、确认密码
- SSL/TLS 设置：启用 SSL 开关、STARTTLS 开关、验证证书开关、CA 证书路径
- 连接测试：显示连接状态、延迟、域功能级别、域名称

## 功能模块设计

### LDAP 模块（Rust）

- 连接管理：LDAPS (SSL/TLS) 连接，支持自定义 CA 证书
- 用户 CRUD：搜索、创建、修改、删除用户
- 密码操作：修改密码（unicodePwd 编码）
- 组管理：添加/移除组成员
- 属性操作：读取/修改任意 AD 属性

### 文件解析模块（Rust）

- CSV 解析：`csv` crate
- Excel 解析：`calamine` crate（支持 .xlsx / .xls）
- 数据验证：必填字段检查、格式校验、重复检测
- 模板生成：生成 CSV/Excel 模板文件

### 配置管理模块（Rust）

- 配置文件格式：JSON
- 存储位置：用户数据目录
- 配置内容：域控地址、端口、Base DN、绑定 DN、SSL 设置
- 密码加密存储

## 错误处理

- LDAP 连接失败：明确提示连接地址/端口/证书问题
- 认证失败：提示 DN 或密码错误
- 批量操作部分失败：逐条记录成功/失败原因，汇总报告
- 文件格式错误：提示具体行号和错误原因

## 安全设计

- 所有 LDAP 通信强制 SSL/TLS
- 管理员密码加密存储
- 操作日志记录所有变更
- 删除操作二次确认
